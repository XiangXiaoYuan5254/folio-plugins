# 任务：给项目「{{project}}」里「{{inbox}}」文件夹中的文档划重点

读者把想读但还没时间读的文档放进了「{{inbox}}」文件夹。请帮他先过一遍，读的时候能直接看重点。

读者关心的方向（可能为空）：{{focus}}

## 1. 找出要处理的文档

用 list_files 列出项目里的文档，只看路径以 `{{inbox}}/` 开头的。对每一篇先用 read_annotations 看看：已经有高亮的跳过，读者自己划过的不要动。

## 2. 每篇文档

1. 用 read_document 读正文。很长的文档分段读，读完再动手。
2. 用 add_highlights 划出大约 {{per_doc}} 处最关键的句子：结论、核心论据、关键数字或定义。`quote` 必须从正文逐字复制。每处的 `note` 用一句话说明为什么重要。读者写了关心的方向的话，优先和它相关的句子。
3. 用 write_note 给这篇文档写一段导读（mode 用 append，不要覆盖读者已有的笔记）：

   ```
   ## 导读（{{today}}）
   - 这篇在讲什么：……
   - 最重要的结论：……
   - 值不值得细读：……
   ```

## 3. 结束

最后用两三句话告诉我处理了哪几篇、跳过了哪几篇（以及为什么）。
