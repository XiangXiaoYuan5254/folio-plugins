# 任务：写今天（{{today}}）的 Hacker News 摘要

读者想花三分钟知道 Hacker News 上今天大家在讨论什么。

## 1. 先看以前写过什么

用 list_files 看看文件夹里已有的摘要。有的话用 read_document 读最近一篇，今天不要重复写已经写过的帖子（除非有了重要的新进展）。

## 2. 读取热门帖子

调用一次 hn_top_stories。它返回的就是今天要写的全部素材，不要再找别的来源。

## 3. 整理

- 按主题分组，例如「AI」「编程与工具」「创业与公司」「科学」「其他」，没有内容的分组不写。
- 每条：标题（链接到原文）、分数和评论数（链接到讨论页）、两句话说明它是什么、为什么大家在讨论。英文标题保留原文，后面给一个中文译名。
- 开头「今日要点」：三条，每条一句话。
- 只写 hn_top_stories 真正返回的内容，不要凭记忆补充，也不要编造链接。

## 4. 写成 HTML

用 create_html 新建 `{{today}} HN 摘要.html`；已经有这个文件的话，改用 `{{today}} HN 摘要（2）.html`。照「输出模板」的结构和样式写，用中文。

写完后用一句话告诉我文件名和今天讨论最热的一件事。
